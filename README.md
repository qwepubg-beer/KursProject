# Система управления тренироваочным процессом 
## Назначение
Система управление тренировочным процессом далее СУТП предназначена для введения записи и контроля тренировочного процесса записи тренирок,приемов пищи,кардио нагрузок,сна и их контроля тренером или пользователем.
## Условия выполнения программы
Для обеспечения функционирования клиентской части приложения СУТП и офисных пакетов для экспорта, а также серверной части (СУБД), требуются следующие аппаратные ресурсы.
### Минимальные технические характеристики (Клиентская часть)
* **Процессор (CPU):** 4-ядерный процессор с тактовой частотой не менее 2.4 ГГц.
* **Оперативная память (RAM):** не менее 8 ГБ.
* **Свободное место на диске (HDD/SSD):** не менее 500 МБ для локальных файлов приложения + дополнительное пространство для сохранения экспортируемых документов.
* **Видеокарта:** с поддержкой DirectX 9.0 или выше.
* **Монитор:** минимальное разрешение экрана 1280×720 пикселей.
### Операционная система
* **ОС для клиентской части:** Microsoft Windows 10 / 11 (64-bit).
### Компоненты среды выполнения и фреймворки
* **Среда выполнения:** Microsoft .NET Framework версии 4.8.
* **Графические библиотеки:** DirectX 9.0c или более поздняя версия (интегрирована в состав современных ОС Windows).
### Программное обеспечение для экспорта данных
* **Офисный пакет:** Microsoft Office 2013 / 2016 / 2019 / 2021 или Microsoft 365.
* **Обязательные компоненты:** Локально установленные классические приложения **Microsoft Word** и **Microsoft Excel** (требуются для корректной работы механизмов COM-interoperability при формировании отчетов).
* **СУБД:** Microsoft SQL Server 2022 (включая бесплатные редакции Express).
## ВЫПОЛНЕНИЕ ПРОГРАММЫ
### Запуск программы
Для запуска приложения необходимо выполнить следующие действия:
1. Убедиться в наличии подключения к серверу СУБД Microsoft SQL Server.
2. На рабочем столе или в директории установки приложения дважды кликнуть левой кнопкой мыши по исполняемому файлу `WpfApp1.exe`.
3. При первом запуске в открывшемся окне авторизации ввести (почту и пароль). Для тестового запуска можете воспользоваться почтой:user@mail.ru и паролем user123 или зарегистрироваться, нажав на кнопку регистрации и введя свои данные. Для тестового запуска в качестве администратора можете воспользоваться почтой:admin@mail.ru и паролем admin123.
### Режимы работы программы
Приложение функционирует в интерактивном (диалоговом) режиме. В зависимости от прав учетной записи пользователя, запущенное приложение поддерживает следующие основные режимы (сценарии) выполнения:
* **Aдминистратор** управление учетными записями(изменение ролей пользователей, а также блокировке пользователей),и управление (добавление,изменения или скрытия) продуктами питания.
* **Пользователь** записи приема пищи, записи активности (кардио нагрузок) и записи результатов измерений,редактирования своего профиля, а так же формирования отчётов и экпорта отчётов в  «Word» или «Excel».
### Выполнение операции экспорта данных
Процесс выгрузки информации в документы происходит по следующему алгоритму:
1. Пользователь в интерфейсе WPF-приложения выбирает пункт в меню (значок диаграммы).
2. Пользователь в интерфейсе WPF-приложения выбирает тип диаграммы на страцнице из combo-box.
3. Нажатием функциональной кнопки «Word» или «Excel» инициализируется процесс генерации.
4. Программа в фоновом режиме запускает экземпляр соответствующего офисного приложения (через механизмы COM-Interop), создает новый документ по заложенному шаблону и заполняет его данными из MS SQL Server.
5. По окончании процесса на экране пользователя автоматически открывается проводник для скачивания готового документа Microsoft Word (`.docx`) или Microsoft Excel (`.xlsx`) для дальнейшего просмотра, редактирования или печати.
### Завершение работы программы
Завершение выполнения программы может быть осуществлено следующими способами:
* **Штатное завершение:** нажатие на графическую кнопку закрытия окна («Выключение» левом нижнем углу главного окна).
* **Аварийное завершение:** происходит при принудительном закрытии процесса `WpfApp1.exe` через Диспетчер задач операционной системы Windows или при потере электропитания ЭВМ.
### Действия при сбоях в работе
* **При потере связи с СУБД MS SQL:** программа выводит на экран диалоговое окно с ошибкой подключения («Сервер базы данных недоступен»). Подключите базу данных, используя конструктор Entity.Framework.SqlServer. Для создания бд используйте скрипт лежащей в папке db.
* **При отсутствии MS Office на рабочем месте:** при попытке экспорта программа перехватывает исключение `COMException` и выводит предупреждение: «Ошибка инициализации MS Word/Excel. Убедитесь, что офисный пакет установлен корректно».
## СООБЩЕНИЯ ОПЕРАТОРУ
В процессе функционирования программы на экран пользователя (оператора) через графический интерфейс WPF могут выводиться информационные, предупреждающие и аварийные сообщения.
### 5.1. Классификация сообщений
Все сообщения программы разделяются на три категории:
1. **Информационные:** Уведомляют об успешном завершении операций (например, сохранение данных или успешный экспорт). Не требуют критических действий со стороны оператора.
2. **Предупреждающие:** Сигнализируют о потенциальных проблемах, некорректных действиях пользователя или отсутствии необходимых условий для выполнения операции(например, Неверный формат введенных данных!).Требуют внимания оператора.
